📚 六西格玛概述

一、什么是六西格玛

六西格玛（Six Sigma）是一种以数据为基础、以客户需求为导向的过程改进方法论。其核心目标是通过减少变异和消除缺陷，使过程输出达到每百万次机会中不超过3.4个缺陷（3.4 DPMO）的质量水平。


六西格玛包含两个层面：

  • 统计学层面：σ（西格玛）是标准差的符号。6σ水平意味着过程均值距离规格界限有6个标准差的距离，缺陷率仅为3.4ppm
  • 管理层面：一套结构化的问题解决方法论（DMAIC），通过项目制推进，追求财务收益和客户满意度的持续提升
核心理念：以客户为中心、以数据为驱动、以项目为载体、以财务为目标。六西格玛不是口号，而是"用数据说话"的科学方法。

三、六西格玛的统计学原理

3.1 正态分布与标准差

正态分布是六西格玛的统计基础。过程输出的质量特性服从正态分布 N(μ, σ²)，其中：

  • μ（均值）：过程输出的中心位置
  • σ（标准差）：过程输出的离散程度，σ越大变异越大
正态分布概率密度函数f(x) = (1 / (σ√(2π))) × e^(-(x-μ)² / (2σ²))

3.2 规格界限与西格玛水平

规格界限（Specification Limits）是客户要求的质量范围：

  • USL（Upper Specification Limit）：规格上限
  • LSL（Lower Specification Limit）：规格下限
  • T（Target）：目标值，通常为规格中心 (USL+LSL)/2

3.3 为什么是3.4ppm？

理论上，6σ水平（均值距规格界限6个标准差）的缺陷率应为0.001ppm。但实际中，过程均值会发生1.5σ的长期漂移（经验数据），因此：

考虑1.5σ漂移后的单侧缺陷率P(X > USL) = P(Z > 6 - 1.5) = P(Z > 4.5) ≈ 3.4ppm

这就是"六西格玛=3.4DPMO"的由来。即长期来看，过程均值最多漂移1.5σ时，单侧超出规格的概率约为百万分之3.4。

关键理解：短期6σ ≠ 长期6σ。短期数据计算的σ水平需要减去1.5才等于长期水平。这是六西格玛中最容易混淆的概念之一。

  1. 高层承诺：CEO和高层管理者的持续支持是第一成功要素

  7. 文化变革：建立"持续改进"的组织文化

📊 假设检验决策流程

第一步：确定假设

  • H₀（原假设）：通常表示"没有差异/没有影响"
  • H₁（备择假设）：通常表示"有差异/有影响"

第二步：选择检验方法（见上表）

第三步：设定显著性水平

  • α = 0.05（最常用）：有5%的风险误判
  • α = 0.01：更严格，误判风险1%

第四步：计算p值并决策

  • p < α → 拒绝H₀ → 差异显著
  • p ≥ α → 不拒绝H₀ → 差异不显著
两类错误：
第一类错误（α风险/生产者风险）：H₀为真但被拒绝 → 误判有差异
第二类错误（β风险/消费者风险）：H₀为假但未被拒绝 → 漏判有差异
检验功效（Power）= 1 - β，通常要求 ≥ 80%
常见陷阱：①混淆统计显著性和实际显著性（p值小≠差异大）②多重比较不修正③忽视假设检验的前提条件（正态性、方差齐性）④过度依赖p值，忽略效应大小

📊 统计学基础

一、描述性统计

1.1 集中趋势度量

指标公式特点
均值（Mean）x̄ = (Σxᵢ) / n利用所有数据，受极端值影响大
中位数（Median）排序后中间值不受极端值影响，适合偏态分布
众数（Mode）出现频率最高的值可用于类别数据

1.2 离散程度度量

方差σ² = Σ(xᵢ - μ)² / N （总体）  |  s² = Σ(xᵢ - x̄)² / (n-1) （样本）
标准差σ = √(σ²)  |  s = √(s²)
极差（Range）R = x_max - x_min
四分位距（IQR）IQR = Q3 - Q1
变异系数（CV）CV = (σ / μ) × 100%
样本方差为什么除以n-1？因为用样本均值x̄来估计总体均值μ会引入偏差，除以n-1（自由度修正）可以得到无偏估计。这就是贝塞尔校正（Bessel's Correction）。

二、概率分布

2.1 正态分布 N(μ, σ²)

最重要的连续分布。六西格玛的统计基础。

区间概率σ水平
μ ± 1σ68.27%1σ
μ ± 2σ95.45%2σ
μ ± 3σ99.73%3σ
μ ± 4σ99.9937%4σ
μ ± 5σ99.999943%5σ
μ ± 6σ99.9999998%6σ

2.2 标准正态分布 Z

Z变换Z = (x - μ) / σ

Z分布是μ=0、σ=1的特殊正态分布。通过Z变换，任何正态分布都可以标准化，便于查表计算概率。

2.3 二项分布

描述n次独立试验中，成功次数为x的概率。适用于计件型数据（合格/不合格）。

二项分布概率P(x) = C(n,x) × p^x × (1-p)^(n-x)
均值 = np  |  方差 = np(1-p)

2.4 泊松分布

描述单位时间/面积内，稀有事件发生次数的概率。适用于计点型数据（缺陷数）。

泊松分布概率P(x) = (λ^x × e^(-λ)) / x!
均值 = λ  |  方差 = λ

2.5 t分布

当样本量小（n<30）且总体标准差未知时，用t分布代替正态分布进行假设检验。

t统计量t = (x̄ - μ₀) / (s / √n)   自由度df = n - 1

2.6 F分布

用于比较两个方差是否相等，是ANOVA和方差检验的基础。

F统计量F = s₁² / s₂²  （较大的方差作分子）

2.7 卡方分布（χ²）

用于检验分类变量的独立性（卡方检验）和方差估计。

卡方统计量χ² = Σ(O-E)² / E  （O=观察值, E=期望值）

三、中心极限定理

中心极限定理（CLT）：无论总体服从什么分布，当样本量n足够大时（通常n≥30），样本均值的分布趋近于正态分布，其均值为总体均值μ，标准差为 σ/√n。
样本均值的标准差（标准误）σ_x̄ = σ / √n
为什么中心极限定理如此重要？
① 它是假设检验的理论基础（即使总体非正态，样本均值仍近似正态）
② 它解释了为什么控制图（X̄-R图）能工作
③ 它使得我们能够用小样本推断总体
④ 它是置信区间计算的基础

四、置信区间

置信区间给出了总体参数可能落在的范围，附带一个置信水平。

总体均值的置信区间（σ已知）CI = x̄ ± Z(α/2) × (σ / √n)
例：95%置信区间 → Z = 1.96
总体均值的置信区间（σ未知，小样本）CI = x̄ ± t(α/2, n-1) × (s / √n)
比例的置信区间CI = p̂ ± Z(α/2) × √(p̂(1-p̂) / n)
置信水平Z值含义
90%1.64590%的区间会包含真实参数
95%1.96最常用
99%2.576更保守，区间更宽

五、假设检验

5.1 假设检验的步骤

  1. 建立假设：H₀（原假设）vs H₁（备择假设）
  2. 选择检验方法：根据数据类型和问题类型
  3. 设定显著性水平α：通常α=0.05
  4. 计算检验统计量：t值、Z值、F值、χ²值
  5. 计算p值：在H₀为真的条件下，观察到当前或更极端结果的概率
  6. 决策：p < α → 拒绝H₀；p ≥ α → 不拒绝H₀

5.2 两类错误与功效

H₀为真H₀为假
不拒绝H₀✅ 正确决策
置信度 = 1-α		❌ 第二类错误（β）
漏判
拒绝H₀❌ 第一类错误（α）
误判		✅ 正确决策
功效 = 1-β
检验功效Power = 1 - β
通常要求 Power ≥ 0.80
α和β的关系：在样本量固定时，减小α会增加β（降低功效）。要同时降低α和β，必须增加样本量。

5.3 常用假设检验速查

六、相关与回归

6.1 相关分析

皮尔逊相关系数r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √[Σ(xᵢ-x̄)² × Σ(yᵢ-ȳ)²]
r ∈ [-1, 1]
r值范围相关性强度
|r| < 0.3弱相关
0.3 ≤ |r| < 0.5中等相关
0.5 ≤ |r| < 0.8较强相关
|r| ≥ 0.8强相关
注意：相关性≠因果性。r只衡量线性关系，非线性关系可能r≈0但强相关。

6.2 简单线性回归

回归方程Y = β₀ + β₁X + ε
估计：ŷ = b₀ + b₁x
最小二乘法min Σ(yᵢ - ŷᵢ)²
b₁ = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
b₀ = ȳ - b₁x̄
决定系数R²R² = SSR/SST = 1 - SSE/SST
R² ∈ [0, 1]，越接近1拟合越好

6.3 多元线性回归

多元回归方程Y = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ + ε

调整R²（Adjusted R²）考虑了自变量个数，防止过度拟合：

调整R²R²_adj = 1 - (1-R²)(n-1)/(n-k-1)
回归分析注意事项：①检查残差的正态性、独立性和方差齐性 ②警惕多重共线性（VIF>10需处理） ③不要外推到数据范围之外 ④R²高不代表模型好，要看残差分析

七、方差分析（ANOVA）

ANOVA用于比较3组及以上均值是否存在显著差异。将总变异分解为组间变异和组内变异。

F统计量F = MSB / MSW = (SSB/(k-1)) / (SSW/(N-k))
k=组数, N=总样本量
变异来源平方和自由度均方
组间SSB = Σnᵢ(x̄ᵢ-x̄)²k-1MSB = SSB/(k-1)
组内SSW = ΣΣ(xᵢⱼ-x̄ᵢ)²N-kMSW = SSW/(N-k)
总计SST = ΣΣ(xᵢⱼ-x̄)²N-1—
决策规则：计算F值 → 查F分布表得到p值 → 若p<α则拒绝H₀（至少有一组均值不同）。注意：ANOVA只告诉我们"有差异"，但不知道"哪组不同"，需要事后比较（Tukey/Dunnett等）。

🎲 假设检验详解

一、基本原理

1.1 两类假设

符号名称含义默认立场
H₀原假设没有差异/没有影响/相等默认成立，除非证据充分
H₁备择假设有差异/有影响/不相等需要证据支持

1.2 两类错误

错误类型定义别称控制方法
第一类错误（α）H₀为真却拒绝生产者风险/误报显著性水平，常取0.05
第二类错误（β）H₀为假却未拒绝消费者风险/漏报功效Power=1-β，目标≥0.80
记忆口诀：α是"冤枉好人"，β是"放过坏人"。降低α会升高β，除非增加样本量n。

二、p值与判定规则

p值定义在H₀为真的前提下，出现当前样本结果或更极端结果的概率
判定规则p < α → 拒绝H₀（差异显著）；p ≥ α → 不能拒绝H₀
p值三大误区：①p值不是"H₀为真的概率"；②p>0.05不等于"两者相同"，只是证据不足；③统计显著≠实际重要（大样本时微小差异也会显著）。

三、检验方法选择路径

数据类型比较对象参数方法非参数替代
连续型（正态）单组 vs 标准值单样本t检验符号检验 / Wilcoxon
两组独立独立双样本t检验Mann-Whitney U
两组配对配对t检验Wilcoxon符号秩
连续型三组及以上均值ANOVA（F检验）Kruskal-Wallis
计数型（频数）比例/关联性卡方检验Fisher精确检验
连续型方差齐性Bartlett检验Levene检验（非正态稳健）
选择三问：①数据是连续还是计数？②几组比较？③正态吗？方差齐吗？→ 正态用参数检验，非正态先试Box-Cox变换，仍不行用非参数检验。

四、t检验实务

单样本tt = (x̄ - μ₀) / (s/√n)，自由度df = n-1
双样本tt = (x̄₁ - x̄₂) / √(s₁²/n₁ + s₂²/n₂)
配对tt = d̄ / (s_d/√n)，d为每对数据之差

实例

改善后抽25件：均值20.05、标准差0.12、目标20.00 → t=(20.05-20.00)/(0.12/√25)=2.08，df=24，p≈0.048<0.05，均值显著偏离目标，需要调整。

五、ANOVA方差分析

5.1 原理

比较3组及以上均值：把总变异分解为组间变异（处理引起）+组内变异（随机误差），用F值判断组间差异是否显著。

F值F = MS组间 / MS组内 = [SS组间/(k-1)] / [SS组内/(N-k)]

5.2 事后比较

方法用途
Tukey HSD所有组两两比较（最常用）
Dunnett各组只与对照组比，功效更高
Bonferroni比较次数少时用，偏保守
注意：ANOVA显著只说明"至少有两组不同"，具体哪两组要看事后比较；多组反复做t检验会放大第一类错误。

六、卡方检验

统计量χ² = Σ (观测频数O - 期望频数E)² / E
类型用途自由度
拟合优度检验实际分布 vs 理论分布类别数-1
独立性检验两个分类变量是否相关(行-1)×(列-1)

使用条件：每个单元格期望频数E≥5，否则合并类别或改用Fisher精确检验。

📈 回归与相关分析

一、相关分析

Pearson相关系数r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √[Σ(xᵢ-x̄)² · Σ(yᵢ-ȳ)²]
|r|范围线性相关强度
0.0 ~ 0.3弱相关
0.3 ~ 0.7中等相关
0.7 ~ 1.0强相关
三大纪律：①相关≠因果（冰淇淋销量与溺水人数同涨，真凶是夏天）；②r只度量线性关系，先画散布图再看r；③异常值会严重扭曲r，先剔除或分层处理。

二、一元线性回归

模型y = a + bx（最小二乘法：残差平方和最小）
斜率b = Σ(xᵢ-x̄)(yᵢ-ȳ) / Σ(xᵢ-x̄)²
截距a = ȳ - b·x̄
决定系数R² = SSR/SST（模型解释的变异比例；R²=0.85 → 自变量解释了85%的变异）

回归显著性：对斜率b做t检验（H₀: b=0），或对整体做F检验，p<0.05说明回归关系显著。

三、残差分析（模型体检）

残差图形态诊断结论处理方法
随机散布、无规律模型合适 ✅-
喇叭口/漏斗形异方差对y做log/√变换
弯曲趋势缺高次项（非线性）加x²项或响应面法
随时间规律变化自相关检查过程稳定性/Durbin-Watson

四、多元回归

模型y = b₀ + b₁x₁ + b₂x₂ + … + bₖxₖ

多重共线性诊断

VIF方差膨胀因子VIF = 1/(1-Rⱼ²)；VIF > 10 → 严重共线性

处理方法：删除高VIF变量、逐步回归、主成分回归、岭回归。

模型评价指标

指标含义要求
调整R²解释变异比例（惩罚变量个数）越高越好
残差标准误S预测精度越小越好
各系数p值变量显著性< 0.05
实务提醒：回归用于预测看R²和S，用于解释看系数p值；变量不是越多越好，遵循"少而精"，且一定要结合业务意义筛选。

方法做法适用场景

二、中心极限定理与置信区间

中心极限定理（CLT）：无论总体服从什么分布，当n≥30时，样本均值的抽样分布近似正态分布 N(μ, σ/√n)。这是所有均值推断的理论基石。
均值的95%置信区间x̄ ± 1.96 × (s/√n)

例：n=36，x̄=50.2，s=3 → CI = 50.2 ± 1.96×(3/6) = [49.2, 51.2]，有95%把握总体均值在此区间内。

三、样本量计算

估计均值所需样本量

公式n = (Z·σ/E)²，E为允许误差

例：σ=2.5，希望误差E≤0.5（95%置信）：n=(1.96×2.5/0.5)²≈96件。

估计不良率所需样本量

公式n = Z²·p(1-p)/E²

例：预估p=5%，误差±2%：n=1.96²×0.05×0.95/0.02²≈451件。

实务要点：①σ未知先做预试验（试抽20~30件估计）；②p未知时取p=0.5最保守（n最大）；③样本量翻4倍，误差才减半（误差∝1/√n），成本效率递减。

一、过程能力概述

过程能力是指过程在统计受控状态下，输出满足规格要求的能力。

前提条件：①过程必须处于统计受控状态（无特殊原因变异）②数据必须近似正态分布 ③规格界限已明确 ④测量系统已通过MSA验证

二、过程能力指数

2.1 Cp — 潜在过程能力指数

衡量过程变异与规格宽度的比值，不考虑过程中心是否偏移。

Cp（潜在过程能力）Cp = (USL - LSL) / (6σ̂)
σ̂ = R̄/d₂ （短期标准差估计）
Cp值评价σ水平
Cp < 1.00❌ 不足<3σ
1.00 ≤ Cp < 1.33⚠️ 勉强3-4σ
1.33 ≤ Cp < 1.67✅ 充足4-5σ
1.67 ≤ Cp < 2.00✅ 优秀5-6σ
Cp ≥ 2.00🌟 卓越≥6σ

2.2 Cpk — 实际过程能力指数

考虑过程中心偏移的实际能力。Cpk ≤ Cp，当中心无偏移时Cpk = Cp。

Cpk（实际过程能力）Cpk = min[(USL - μ)/(3σ̂), (μ - LSL)/(3σ̂)]
Cpk与Cp的关系Cpk = Cp × (1 - |K|)
K = |μ - T| / (USL - LSL)/2  （偏移系数）
Cp vs Cpk： Cp衡量"潜在能力"（变异够不够小），Cpk衡量"实际能力"（中心偏没偏）。Cp高Cpk低=变异小但中心偏了→需要调中心；Cp低=变异大→需要减变异。

2.3 Pp / Ppk — 过程性能指数

使用长期标准差计算，反映过程的实际长期表现。

PpPp = (USL - LSL) / (6s)
Ppk = min[(USL - μ)/(3s), (μ - LSL)/(3s)]
s = √[Σ(xᵢ-x̄)²/(n-1)]（长期标准差）

2.4 Cpk vs Ppk 的区别

📈 SPC统计过程控制

一、SPC基本概念

统计过程控制（Statistical Process Control）是利用控制图监控过程变异，区分普通原因和特殊原因变异的统计方法。

两类变异：
普通原因变异：过程固有的、自然的、随机变异。只能通过改变过程系统来减少（如更换设备、改进工艺）。→ 系统问题
特殊原因变异：非随机的、异常的、可识别的变异。可以通过消除特定原因来消除（如操作错误、设备故障）。→ 局部问题

二、控制图原理

控制图以时间序列图为基础，加入三条控制线：

控制图三线UCL = μ + 3σ （控制上限）
CL = μ （中心线）
LCL = μ - 3σ （控制下限）
控制限 vs 规格限：控制限来自过程数据（过程能做什么），规格限来自客户要求（客户要什么）。控制限在规格限之内=过程有能力；超出=无能力。

三、控制图类型选择

3.1 连续型数据控制图

控制图适用场景子组大小特点
X̄-R图均值与极差监控2-9最常用，简单直观
X̄-S图均值与标准差监控≥10大子组时更精确
I-MR图单值与移动极差1每次只取一个数据

3.2 离散型数据控制图

控制图数据类型子组大小监控对象
NP图计件（不合格品数）固定不合格品数
P图计件（不合格品率）可变不合格品率
C图计点（缺陷数）固定单位缺陷数
U图计点（单位缺陷率）可变单位面积缺陷率
选择口诀：
连续数据→子组=1用I-MR，2-9用X̄-R，≥10用X̄-S
计件数据→子组固定用NP，子组变化用P
计点数据→子组固定用C，子组变化用U

📐 MSA测量系统分析

一、MSA概述

测量系统分析（Measurement System Analysis）是评估测量系统是否可靠的方法。垃圾数据进去，垃圾结论出来——在分析过程之前，必须先验证测量系统。

测量系统的5项统计特性：
① 偏倚（Bias）：测量值与基准值的系统性差异
② 线性（Linearity）：偏倚随量程变化的程度
③ 稳定性（Stability）：偏倚随时间变化的一致性
④ 重复性（Repeatability）：同一操作者、同一量具多次测量的变异（设备变异 EV）
⑤ 再现性（Reproducibility）：不同操作者用同一量具测量的变异（操作者变异 AV）

二、GR&R研究

GR&R（量具重复性和再现性）是MSA中最常用的方法。

2.1 研究设计

  • 操作者：≥2人（通常3人）
  • 零件：≥5个（通常10个），覆盖整个规格范围
  • 重复次数：≥2次（通常3次）
  • 总测量次数 = 操作者数 × 零件数 × 重复次数（如3×10×3=90次）

2.2 计算方法

GR&R%%GR&R = (σ_GR&R / σ_total) × 100%
σ_GR&R = √(σ_EV² + σ_AV²)
σ_EV = R̄_eq / d₂ （重复性）
σ_AV = √[(R̄_op/d₂)² - σ_EV²/(nr)] （再现性）
NDC（区分度）NDC = 1.41 × (σ_part / σ_GR&R)
NDC应 ≥ 5，表示测量系统能区分足够多的类别

2.3 验收标准

%GR&RNDC评价决策
< 10%> 14✅ 优秀可接受
10% - 30%5 - 14⚠️ 有条件接受视重要性而定
> 30%< 5❌ 不可接受必须改进

三、偏倚与线性分析

3.1 偏倚

偏倚偏倚 = 测量均值 - 基准值
%偏倚 = (偏倚 / 过程变异) × 100%

用t检验判断偏倚是否显著（p<0.05则偏倚显著）。

3.2 线性

评估偏倚在整个量程内是否一致。用回归分析计算偏倚与基准值的关系。

线性度%线性 = (|斜率b| × 过程变异) / (过程变异 × 100%) × 100%

🧪 DOE试验设计

一、DOE概述

试验设计（Design of Experiments）是系统地规划和分析试验，以最高效率获取最大信息量的统计方法。OFAT（一次一因子法）效率低且无法发现交互作用，DOE可以同时研究多个因子。

DOE vs OFAT：
OFAT：每次只变一个因子，需要3^(k-1)次试验才能找到最优
DOE：同时变化多个因子，用2^k次试验即可，且能发现交互作用

二、DOE术语

术语含义
因子（Factor）影响输出的输入变量X
水平（Level）因子的取值，如温度的高(-1)/低(+1)
响应（Response）试验的输出结果Y
主效应（Main Effect）因子变化对响应的独立影响
交互效应（Interaction）两个因子组合产生的额外影响
重复（Replicate）同一试验条件重复执行多次
随机化（Randomization）试验顺序随机，消除时间趋势
区组化（Blocking）将同质条件分组，消除噪声因子

⚠️ FMEA失效模式与效应分析

一、FMEA概述

FMEA（Failure Mode and Effects Analysis）是一种系统化的风险分析方法，用于识别潜在的失效模式、评估其影响和风险优先级，并制定预防措施。

FMEA类型关注点适用阶段
DFMEA（设计FMEA）产品设计缺陷设计阶段
PFMEA（过程FMEA）制造过程缺陷工艺规划阶段
SFMEA（系统FMEA）系统级故障概念阶段

二、FMEA分析步骤

  1. 列出过程步骤/功能：用流程图分解
  2. 识别潜在失效模式：每个步骤可能出什么问题？
  3. 描述失效后果：对客户/下工序的影响
  4. 评定严重度（S）：后果有多严重（1-10分）
  5. 识别潜在失效原因：为什么会发生？
  6. 评定频度（O）：发生概率（1-10分）
  7. 识别现有控制：如何预防？如何探测？
  8. 评定探测度（D）：能否及时发现（1-10分）
  9. 计算RPN：RPN = S × O × D
  10. 制定改进措施：优先处理高RPN项

答案：A 双侧检验与置信区间等价：参数假设值落在区间内则不能拒绝，落在区间外则拒绝。
Q39.测量系统不合格（%GR&R>30%）时直接做假设检验，会导致？
  • A. 功效自动提高
  • B. 测量噪声混入数据，可能掩盖真实差异或产生假显著
  • C. 结果更准确
  • D. α自动变小
答案：B 垃圾进垃圾出：先做MSA确保测量系统可靠，再收集数据做检验，这是Measure阶段的标准顺序。
