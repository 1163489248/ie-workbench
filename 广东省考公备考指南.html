第一部分　广东省考考情分析

一、考试概况

广东省公务员考试（简称「广东省考」）由广东省委组织部统一组织，每年上半年举行，通常在3月公告、4月笔试。笔试公共科目为行政职业能力测验（行测）和申论两科，部分岗位加考专业科目。

科目题量时长满分题型
行政职业能力测验100题90分钟100分客观题（单选）
申论4~5题150分钟100分主观题（写作）

二、行测题型分布（参考近年）

模块题量参考分值建议用时
言语理解与表达约15题15~18分15分钟
数量关系约15题15~18分15分钟
判断推理约35题30~35分30分钟
资料分析约20题18~20分20分钟
常识判断约15题10~12分8分钟

注：各年题量与分值略有调整，以当年公告为准。

三、广东省考特点

与其他省考的差异化要点
  • 数量关系含数字推理：广东省考保留数字推理题型（部分省份已取消），需重点掌握数列规律
  • 常识判断侧重广东省情：粤港澳大湾区、广东历史文化、岭南经济等本地特色内容比例较高
  • 申论聚焦广东发展：主题常涉及制造业当家、百千万工程、数字政府、绿美广东等本省热点
  • 行测题量大、时间紧：100题/90分钟，平均不到1分钟/题，对速度要求极高
  • 科学推理题：广东省考近年新增科学推理（物理/化学基础），需掌握初中理化核心知识
广东省考行测建议答题顺序：常识判断（快速过）-> 资料分析（稳拿分）-> 判断推理（量大但规律性强）-> 言语理解（需细读）-> 数量关系（留最后，会做的做、不会的猜）。

第二部分　行测知识点精要

模块一　言语理解与表达

言语理解与表达主要考查对文字材料的准确理解和规范表达，核心题型包括选词填空、片段阅读和语句表达三大类。

一、选词填空
解题三步法
  1. 读语境：分析空缺处前后文的逻辑关系（转折、递进、并列、因果等），确定空缺词的语义方向
  2. 辨词义：区分近义词的语素差异、感情色彩、语体色彩、搭配习惯
  3. 代入验：将最优选项代入原文，检验是否通顺连贯
近义词辨析方法
  • 语素分析法：拆解词语的语素，比较不同语素含义。如「遏制/遏止」——「制」侧重控制，「止」侧重停止
  • 语境分析法：看空缺处需要褒义/贬义/中性，需要主动/被动，需要抽象/具体
  • 搭配习惯法：固定搭配不可随意替换。如「提高……水平」「改善……关系」「增进……友谊」
  • 程度轻重法：同义词语义程度有轻重之分。如「失望>沮丧>失落」「批判>批评>指责」
常考成语辨析（高频）
成语含义易混/注意事项
南辕北辙行动与目的相反强调目的与行动矛盾
背道而驰方向相反，比喻背离正确目标强调方向相反
相辅相成两事物互相配合，互相辅助强调配合关系
相得益彰两者配合更能显出各自长处强调效果增强
潜移默化不知不觉受到影响强调无形中的变化
耳濡目染耳朵经常听，眼睛经常看，无形中受影响强调见闻的影响
不以为然不认为是对的，表示不同意易混「不以为意」（不在乎）
无可厚非没有可过分指责的易混「无可非议」（完全正确）
二、片段阅读
行文脉络分析法
结构类型特征主旨位置
总分结构先总述观点，后分述论据总述句（首句）
分总结构先分述论据，后总述结论总述句（尾句）
总分总结构首尾呼应，中间展开首句或尾句
转折结构「但是/然而/不过」等转折词转折后
递进结构「不仅……更/甚至……」递进后（最后一层）
并列结构多个并列分句，无主次概括各分句共性
主旨概括 vs 意图判断
  • 主旨概括题：问「这段文字主要说的是/概括最准确的是」-> 答案忠于原文，不引申
  • 意图判断题：问「这段文字意在说明/想表达的是」-> 在主旨基础上适度引申，常指向对策/呼吁
  • 关键区分：如果原文已有明确对策，主旨和意图答案一致；如果原文只讲问题，意图题常选解决问题的选项
细节判断题常见陷阱
  • 偷换概念：将原文中的A偷换为B（如「主要」->「唯一」）
  • 无中生有：选项内容原文未提及
  • 以偏概全：将原文的部分说成全部
  • 因果倒置：颠倒原文的因果关系
  • 时态混淆：将「将来时」说成「已完成」
  • 绝对化表述：原文说「可能」，选项说「必然」
三、语句表达
语句排序题解题步骤
  1. 看选项定首尾：从选项入手，排除不能做首句的（如代词开头、关联词后半部分开头）
  2. 找逻辑关系：寻找句子间的指代关系（这/那/它）、时间顺序、空间顺序、逻辑递进
  3. 确定捆绑组：有关联的句子必须相邻，形成捆绑组
  4. 代入验证：将排列好的顺序通读，检验连贯性
语句填充题
  • 分析空缺处位置：首句（总起）、中间（承上启下）、尾句（总结）
  • 保持话题一致：前后文主体对象不能突变
  • 注意逻辑衔接：前后句的关联词要匹配

模块二　数量关系

数量关系包括数字推理和数学运算两部分。广东省考保留数字推理题型，这是与部分省份的显著区别。

一、数字推理
八大数列规律
类型特征示例
等差数列相邻两项差为常数2,5,8,11,14 -> 公差3
等比数列相邻两项比为常数2,6,18,54 -> 公比3
和数列前两项之和=第三项1,2,3,5,8,13
积数列前两项之积=第三项1,2,2,4,8,32
幂次数列各项可化为幂次形式1,4,9,16,25 -> n^2
分数数列各项为分数，分子分母分别看规律1/2, 2/3, 3/4, 4/5
组合数列交叉/分组两套规律1,4,2,5,3,6（奇偶项分开看）
递推数列前项经运算得后项1,2,5,14,41 -> x3-1
数字推理「看三步」
  1. 看趋势：递增->等差/等比/幂次；递减->等差/等比；震荡->组合/递推
  2. 做差/做商：一次差无规律->做二次差；差中有规律->多级等差
  3. 看特征：有分数->分数数列；有1,4,9,16->幂次；项数多且交替->组合数列
二、数学运算
工程问题
工作总量 = 工作效率 x 工作时间
  • 常设工作总量为各时间的最小公倍数，化简计算
  • 合作问题：合效率 = 各自效率之和
  • 交替施工：注意每个人的实际工作时间
行程问题
路程 = 速度 x 时间
  • 相遇问题：路程和 = 速度和 x 时间
  • 追及问题：路程差 = 速度差 x 时间
  • 多次相遇：第n次相遇时，两人路程和 = n x 全程（相向而行）
  • 流水行船：顺流速度 = 船速 + 水速；逆流速度 = 船速 - 水速
利润问题
利润 = 售价 - 成本　　利润率 = 利润 / 成本 x 100%
售价 = 成本 x (1 + 利润率)　　打折后售价 = 定价 x 折扣
  • 注意「定价」与「售价」的区别：定价是标价，售价是实际卖价
  • 打折是在定价基础上打折，不是在成本基础上
排列组合与概率
A(n,m) = n!/(n-m)!　　C(n,m) = n!/[m!(n-m)!]
  • 分类用加法（「或」关系），分步用乘法（「且」关系）
  • 至少问题：正难则反——总数 - 反面情况
  • 相邻问题：捆绑法（视为一个整体）
  • 不相邻问题：插空法（先排其他，再插空）
容斥原理
|A∪B| = |A| + |B| - |A∩B|
|A∪B∪C| = |A|+|B|+|C| - |A∩B|-|A∩C|-|B∩C| + |A∩B∩C|
  • 两集合：都不满足 = 总数 - (|A|+|B|-|A∩B|)
  • 注意「至少满足一个」与「都满足」的区分
常用速算技巧
  • 特值法：设未知量为特殊值（如1、100），简化计算
  • 代入排除法：将选项代入验证，排除错误项
  • 比例法：利用比例关系快速求解
  • 整除特性：利用整除关系排除选项

模块三　判断推理

判断推理是行测中题量最大的模块（约35题），含图形推理、定义判断、类比推理和逻辑判断四类。

一、图形推理
图形推理考点体系
大类考点识别特征
数量类点（交点/顶点）线条交叉明显
线（直线/曲线/笔画）图形线条变化
角（锐角/直角/钝角）含角的图形
面（封闭区域数）封闭图形多
位置类平移元素位置有规律移动
旋转/翻转图形方向变化
样式类遍历每行/列含所有元素各一次
运算（叠加/相减/求同/求异）两图叠加成第三图
属性类对称性（轴/中心对称）图形有对称特征
曲直性全直线/全曲线/混合
封闭性开放/封闭
图形推理「看图三步」
  1. 看整体：图形组成相同->位置类；组成相似->样式类；组成不同->数量类或属性类
  2. 找规律：从最明显的特征入手（如对称性->曲直性->封闭性->数量）
  3. 验证规律：将规律代入所有图形验证一致性
二、定义判断
核心成分分析法
  1. 主体：谁实施的这个行为？（如「行政机关」「企业」「个人」）
  2. 客体：行为作用的对象是谁？
  3. 目的：为了什么目的？（「为了……」「以……为目的」）
  4. 方式：通过什么方式？（「通过……」「以……方式」）
  5. 条件：在什么条件下？（「在……情况下」「当……时」）
  6. 结果：产生什么结果？

解题时将选项与定义的各成分逐一比对，有一个成分不符即可排除。

三、类比推理
常考逻辑关系
类别关系示例
逻辑关系全同关系番茄：西红柿
并列关系手机：电脑（同为电子产品）
包含关系水果：苹果（种属关系）
交叉关系大学生：运动员
言语关系近义/反义勇敢：怯懦
象征关系玫瑰：爱情
常识关系对应关系医生：医院：治疗
因果/条件下雨：地湿
类比推理「二级辨析」

当多个选项都符合一级关系时，需进行二级辨析：

  • 词性一致：名词对名词，动词对动词
  • 感情色彩一致：褒义对褒义，贬义对贬义
  • 具体/抽象一致：具体事物对具体事物
  • 顺序一致：A包含B，则选项也应是「大：小」而非「小：大」
四、逻辑判断
翻译推理核心公式
「如果A，那么B」 -> A->B （前推后）
「只有A，才B」 -> B->A （后推前）
逆否命题：A->B 等价于 非B->非A
摩根定律：非(A且B) = 非A或非B ；非(A或B) = 非A且非B
  • 肯前必肯后：A->B，A真->B真
  • 否后必否前：A->B，B假->A假（逆否命题）
  • 否前/肯后不能推：A->B，A假->不确定；B真->不确定
削弱加强题
题型方法说明
削弱否定论点直接反驳结论（最强）
切断联系论据与论点之间无必然联系
另有他因其他因素也可能导致该结果
加强肯定论点直接支持结论
建立联系补充论据到论点的逻辑桥梁
排除他因排除其他可能性
真假推理
  • 找矛盾关系：A与非A必一真一假（「所有都是」与「有些不是」矛盾）
  • 找反对关系：「所有都是」与「所有都不是」至少一假
  • 绕开矛盾，先确定其他命题的真假
  • 回到矛盾，确定矛盾双方的真假

模块四　资料分析

资料分析是行测中「性价比」最高的模块，掌握核心公式和速算技巧后，正确率可达90%以上。

一、核心公式
增长率与增长量
增长率 = (现期量 - 基期量) / 基期量 x 100%
增长量 = 现期量 - 基期量 = 现期量 x 增长率 / (1 + 增长率)
基期量 = 现期量 / (1 + 增长率)
现期量 = 基期量 x (1 + 增长率)
比重相关
比重 = 部分 / 整体 x 100%
部分 = 整体 x 比重
比重升降判断：部分增长率 > 整体增长率 -> 比重上升
平均数与倍数
平均数 = 总量 / 份数
平均数增长率 = (总量增长率 - 份数增长率) / (1 + 份数增长率)
倍数 = A / B　　A是B的几倍 = A/B，A比B多几倍 = A/B - 1
二、速算技巧
五大速算方法
方法适用场景要点
首数法除法运算，选项首位不同只算第一位商，快速定位
尾数法加减运算，选项尾数不同只算末位，简化计算
特征数字法百分数可化为简单分数如 25%=1/4, 33.3%=1/3, 16.7%=1/6
有效数字法乘除运算保留前2~3位有效数字
同位比较法比较大小比较分数的分子分母增长率

三、常见陷阱
资料分析易错点
  • 时间陷阱：「同比」vs「环比」，「一季度」vs「上半年」，注意题干时间范围
  • 单位陷阱：「亿元」vs「万元」，「吨」vs「万吨」，注意单位换算
  • 范围陷阱：「全国」vs「全省」，「规模以上」vs「全部企业」
  • 概念陷阱：「超过」（>）vs「不少于」（>=），「增长了」vs「增长到」
  • 增长量vs增长率：增长量大不代表增长率高，反之亦然

模块五　常识判断

常识判断考查政治、法律、经济、科技、人文历史及广东省情等方面，范围广但每题分值不高，重在日常积累。

一、政治常识
党的二十大精神要点
  • 中心任务：团结带领全国各族人民全面建成社会主义现代化强国、实现第二个百年奋斗目标，以中国式现代化全面推进中华民族伟大复兴
  • 中国式现代化特征：人口规模巨大、全体人民共同富裕、物质文明和精神文明相协调、人与自然和谐共生、走和平发展道路
  • 两步走战略：2020~2035基本实现社会主义现代化；2035~本世纪中叶建成社会主义现代化强国
  • 首要任务：高质量发展是全面建设社会主义现代化国家的首要任务
习近平新时代中国特色社会主义思想
  • 「十个明确」：核心要义的十个方面（2021年十九届六中全会总结）
  • 「十四个坚持」：基本方略
  • 「两个确立」：确立习近平同志党中央和全党的核心地位、确立习近平新时代中国特色社会主义思想的指导地位
二、法律常识
民法典核心要点
  • 民事行为能力：不满8周岁=无民事行为能力；8周岁以上=限制民事行为能力；16周岁以上以劳动收入为主要生活来源=视为完全民事行为能力；18周岁以上=完全民事行为能力
  • 物权编：不动产物权经登记生效；动产物权经交付生效

二、各题型解题方法

归纳概括题
  • 审题：明确概括对象（做法/问题/原因/影响/经验）+ 范围限定 + 字数
  • 找点：回到材料逐段标注与题干相关的要点
  • 加工：同义合并、同类合并，形成逻辑层次
  • 书写：总分结构，关键词前置，条理清晰

格式模板：总括句+分条列述。如「主要做法如下：一是……；二是……；三是……。」

综合分析题
  • 解释型：解释某句话的含义 -> 是什么（表层含义）-> 为什么（深层分析）-> 怎么办（对策/结论）
  • 评价型：对某观点/现象进行评价 -> 表明态度 -> 分析理由 -> 得出结论
  • 比较型：比较两个事物/观点 -> 找相同点 -> 找不同点 -> 得出启示
提出对策题
  • 来源：直接对策（材料中明确给出的建议）+ 间接对策（根据问题反推对策）
  • 对策表述：主体+方式+内容+结果。如「政府应通过完善法规、加大执法力度，规范市场秩序」
  • 针对性：一一对应材料中的问题，不可泛泛而谈
  • 可行性：经济上可承受、技术上可实现、政治上可接受
贯彻执行题（应用文写作）
文种格式要求行文重点
通知标题+主送机关+正文+落款告知事项+具体要求
倡议书标题+称呼+正文+落款背景+倡议内容+号召
工作简报报头+正文+报尾做法+成效+经验
调研报告标题+正文现状+问题+建议
讲话稿标题+称呼+正文开场+主体（做法/要求）+结尾
建议书标题+称呼+正文+落款问题分析+具体建议
文章写作（大作文）
  • 审题立意：从题干和材料中提取核心论点，确保立意准确、不跑题
  • 结构安排：
    • 标题：中心论点的浓缩（10~15字）
    • 开头（150字）：引入话题+亮明观点
    • 分论点（3个，各250字）：每段一个分论点+论据+分析
    • 结尾（150字）：总结升华+展望
  • 论证方法：举例论证、道理论证、对比论证、比喻论证
  • 语言要求：规范、准确、有一定文采，避免口语化
